## 2.1 历史

JDBC API 是一项成熟的技术，最早于 1997 年 1 月发布。最初的 JDBC API 主要为 SQL 数据库提供基本的调用级接口。随后，JDBC 2.1 规范和 JDBC 2.0 可选包规范扩展了 API 的范围，以支持更复杂的应用程序，并满足应用服务器代替应用程序管理 JDBC API 使用的需要。

JDBC 3.0 规范通过补充一些规模较小但十分重要的功能，进一步完善了这套 API。JDBC 4.2 则主要关注两个目标：改善在 Java 平台上使用 SQL 的开发体验；提供面向企业应用的功能，帮助各类工具和上层 API 更好地管理 JDBC 资源。

## 2.2 目标概述

下面介绍 JDBC API 的整体设计目标，以及 JDBC 4.2 API 遵循的设计理念：

### 1. 适应 Java EE 和 Java SE 平台

JDBC API 是 Java 平台的组成部分。JDBC 4.2 API 应与 Java 企业版和 Java 标准版平台的整体方向保持一致。此外，Java SE 平台的发展带来了新的功能和语言改进，本规范也广泛使用了这些能力。

### 2. 与 SQL:2003 保持一致

JDBC API 为用 Java 编程语言编写的应用程序提供对标准 SQL 的编程访问。JDBC 3.0 力求确保对 SQL99 功能子集的支持，这些功能预计会被业界广泛支持。同样，JDBC 4.2 对 SQL:2003 的支持也集中在该规范的主要组成部分上，这些部分预计会在可预见的未来得到业界支持。

### 3. 提供供应商中立的通用功能访问

JDBC API 力求让应用程序充分访问不同供应商普遍支持的功能，达到与本地应用程序相当的功能覆盖程度。同时，API 也必须保持足够的通用性和灵活性，以适应不同的实现。

### 4. 保持对 SQL 的关注

JDBC API 的重点一直是从 Java 编程语言访问关系数据。这一目标在 JDBC 3.0 API 中已经明确提出，并且仍然是本规范的核心原则。围绕简化开发所做的 API 与工具改进，依然服务于基于 SQL 的软件开发需求。当然，这并不排斥与 XML、CORBA 以及非关系型数据等其他技术的交互。

### 5. 为工具和高级 API 提供基础

JDBC API 提供了一套标准 API，用于访问各种底层数据源或遗留系统。通过 JDBC API 这一抽象层，具体实现之间的差异被屏蔽了，这使它成为构建可移植工具和应用程序的理想基础。由于它本质上是从 Java 编程语言到 SQL 的调用级接口，因此也很适合作为更高层能力的基础，例如企业 JavaBeans（EJB）中的容器管理持久化、`SQLJ` 以及 JDBC RowSet 实现。

### 6. 保持简单

JDBC API 旨在提供简单、直接、易用的接口，并允许在此基础上构建更复杂的功能。为此，API 定义了较多职责单一、规模较小的方法，避免将多种用途集中在少数复杂方法中，再通过控制标志参数区分行为。

### 7. 增强可靠性、可用性和可扩展性

可靠性、可用性和可扩展性是 Java EE 和 Java SE 平台持续关注的目标，也是 Java 平台未来的发展方向。JDBC API 通过改进资源管理、跨逻辑连接的预编译语句重用和错误处理等功能，支持这些目标。

### 8. 保持与现有应用程序和驱动程序的向后兼容性

现有的支持 JDBC 技术的驱动程序以及依赖这些驱动程序的应用程序，必须能够继续在支持 JDBC 4.2 API 的 Java 虚拟机实现中运行。仅使用较早版本 JDBC API 中已定义能力的应用程序，不应因升级到 JDBC 4.2 而被迫修改代码。

### 9. 与 JDBC RowSet 实现的密切关联

Java SE 包含由 JDBC RowSet 规范（JSR-114）定义的标准 JDBC RowSet 实现。本规范通过工具类和元数据语言方面的相关功能，帮助开发者将 JDBC 应用程序迁移到 JDBC RowSet 模型。该模型支持断开连接后的数据访问，也支持以 XML 形式处理关系数据存储。

### 10. 允许与连接器的向前兼容性

连接器架构规定了打包和部署资源适配器的标准方式，使 Java EE 容器能够将自身的连接、事务和安全管理与外部资源管理整合起来。JDBC API 为 JDBC 驱动程序到连接器架构提供了迁移路径。使用 JDBC 技术的产品供应商应该能够逐步向实现连接器 API 迈进。预计驱动程序供应商会为现有的数据源实现编写资源管理器包装层，从而在连接器框架中重用这些实现。

### 11. 明确指定要求

JDBC 合规性要求应当清晰明确，便于识别。JDBC 规范和 API 文档（Javadoc）将阐明哪些功能是必需的，哪些是可选的。
