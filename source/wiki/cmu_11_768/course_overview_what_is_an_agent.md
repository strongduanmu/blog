## 课程信息

- 官网主题：Course Overview: What Is an Agent?
- 所属模块：智能体能力
- 授课日期：2026-08-25

## 学习重点

- 从感知、推理、规划、行动与环境交互的闭环理解 LLM 智能体。
- 区分模型能力、智能体 Harness 与外部环境各自承担的职责。
- 理解课程从构建、评测、训练到研究项目的整体路径。

## 核心问题

- 什么条件使一个 LLM 应用成为智能体系统？
- ReAct 循环如何连接推理、工具调用、观察与下一步行动？
- 哪些能力应由模型训练获得，哪些能力更适合由 Harness 提供？
